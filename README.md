# 네트워크보안 및 블록체인 팀프로젝트
블록체인을 활용한 공동구매 서비스

Geth 기반 Private Ethereum Network + MetaMask 연동 거래
Solidity + Remix IDE를 통해 smart contract 구현

- 블록체인 기술을 활용한 투명한 공동구매 관리 서비스
- 참여 기록, 결제 및 정산 과정의 위조/조작 방지
